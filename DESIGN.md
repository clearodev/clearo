# CLEARO UI Direction: Retro-Futuristic "Clean Sci-Fi"

## Principles

- **Pitch Black Foundation:** Use `#000000` as the absolute background to create a tech-noir void.
- **Terminal Green Accents:** Use `#00cc88` for primary accents and signals. It should be legible and clear without being overly bright or harsh.
- **High-Contrast Data:** Text and data must pop against the black background using a soft, muted pale green (`#c2d9cc`).
- **Sci-Fi Typography:** 
    - **Display/Headings:** `Orbitron` for a geometric, futuristic feel.
    - **Functional/Body:** `Space Mono` for a classic monospaced terminal aesthetic.
- **Sharp Precision:** Use thin, sharp borders and rigid grids. Avoid soft shadows, decorative gradients, or glow effects to maintain a "Clean Sci-Fi" look.
- **Dense & Functional:** The UI should feel like a high-density public registry or terminal readout. Readability is paramount.

## Rules

- No decorative gradients.
- No glow effects as primary affordances.
- No shadows for layout decoration.
- No animation unless explicitly requested.
- No letter-spacing overrides.
- Dense UI is mandatory, but data surfaces must remain readable.
- Icon-only buttons need accessible labels.
- Headings use balanced wrapping where supported.
- Body copy uses readable line length and pretty wrapping where supported.
- Numbers and registry values should be easy to scan and tabular.
